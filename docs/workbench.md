# 山城地研使用说明

## 应用界面

空间总览展示不透水面净扩张、土地覆盖构成、指标排行和区县历年档案。用大屏按钮切换深色展示，播放四期时可暂停并继续点选区县。地图色阶在同一指标和区组下跨期统一。转移矩阵可切换当前区组和所选区县，点格子查看面积或下载 CSV。矩阵的九类编码与 CLCD 一致，采用四期共同有效覆盖范围。三个阶段共 63 张区级矩阵、5,103 条转移单元，含零面积。同一地类前后保持的面积位于对角线。2020—2022 年，耕地转入不透水面的面积为 58.54 km²。

评价实验室默认采用 2020、2022 年的 42 条观测。选择四期参照后可试算早期年份。权重滑杆按有效指标归一化。单区情景调整当前年份的面积、人口或当年现价产出，重新计算全部样本的标准化、理想点和排名。试算 CSV 保留权重、样本范围和情景变化。数据查询按区名或代码、年份、专题过滤，支持导出。案例数据覆盖 2010、2015、2020、2022 年。页面即时重算以已加载的数据为准。

研究助手按问题中的区名、年份和指标查找记录，并执行合计、排名、区县差额、跨期比较或情景解读。离线助手使用字符 n-gram TF-IDF 意图检索与确定性计算。网页版可接入运行于当前服务主机的 Ollama，由模型从计算结果中选取相关证据，页面显示原始统计行。GDP 为名义价格，2010 和 2015 年部分经济数据按待复核材料处理。

## 构建与验证

- Android 使用 JDK、Android SDK API 35、Build Tools 35.0.0，执行 `bash clients/android/build.sh`。交付 APK 使用演示签名。重新构建时可通过 `CQ_ANDROID_KEYSTORE` 提供相同演示密钥库，以支持覆盖安装。
- Windows 和 Linux 使用 Go 1.24 执行 `sh clients/desktop/portable/build.sh`，包内嵌应用和数据，程序通过本机浏览器的独立应用窗口显示工作台。桌面数据查询的 Tk 版本通过 `python clients/desktop/package.py` 构建。
- 研究计算可执行 `node --test tests/test_client.cjs` 与 `python -m unittest discover -s tests -v`。地类转移在原始栅格复算步骤中生成，年度类别合计和不透水面新增、减少都可用矩阵核对。
