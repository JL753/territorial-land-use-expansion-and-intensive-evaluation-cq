# 山城地研统一工作台界面改版

## 改版目标

把原先分散的多个页面收敛为一个连续的 GIS 研究工作台。此次改版只重组导航和视觉呈现，不改变研究算法、数据口径、API 路径、地图图层 ID、表格字段或已有交互控件 ID。

## 信息架构

- **研究工作台**：空间总览、评价实验室、指标关系、分析中心、数据查询、研究助手、研究简报。
- **空间探索**：全域三维专题、两江立体图、21 区县三维。
- **数据与项目**：数据中心、毕设工作台。
- **扩展工具**：桌面分析台、口袋区县档案。

主导航固定在左侧；当前页面的操作按钮放在顶部工具栏。首页原有七个研究模块按钮迁入侧栏，页面入口不再重复出现在顶部。桌面和手机专用客户端保留各自的数据操作模式，但使用同一套品牌色、间距和组件语言。

## 视觉系统

- 主色：山城深海蓝，强调色：地理信息青蓝，辅助色：地形暖金。
- 页面背景采用低对比度浅灰蓝；地图仍保留适合空间阅读的深色或浅色底图。
- 统一卡片圆角、边框、阴影、按钮、表格、焦点状态和排版层级。
- 信息呈现优先级：地图与研究结论 > 指标卡片与图表 > 参数控制 > 来源与方法说明。
- 重要研究口径保留，长说明不再抢占首屏。

## 响应式规则

- 宽屏：252 px 固定侧栏 + 顶部工具栏 + 内容工作区。
- 中等宽度：侧栏收敛为图标栏，避免挤压地图。
- 窄屏：侧栏切换为抽屉；地图优先占据首屏；手机档案继续使用专用底部导航。
- 打印研究简报时隐藏导航和工具栏。

## 兼容与缓存

- workspace.js 通过移动原有 DOM 节点复用现有事件监听，不重建页面功能控件。
- workspace.css 作为统一视觉层加载在各页面原有样式之后。
- Service Worker 升级到 v16，并预缓存统一样式与脚本，避免离线时出现旧导航和新内容混用。
- CI 对统一工作台脚本执行 Node 语法检查，并验证所有页面都加载统一资源。
