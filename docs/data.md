前期访问官方目录时，云环境的 HTTPS 代理返回 403。后续用户提供了四期 CLCD 裁剪件、统一网格的区归属栅格、转至 WGS84 的展示边界，以及完整的社会经济转录表。附件解压到本地 `inputs/`。仓库提供汇总和展示成果供直接运行。参见 [实测数据分析](landcover-results.md) 和 [社会经济数据核查](socioeconomic-results.md)。

## 边界和栅格

- 使用 [21 区代码表](../data/districts.csv) 匹配固定边界。按既定行政边界基准核对名称、代码、辖区变化和功能区。每区合并为一个有效 Polygon 或 MultiPolygon，保持相邻边界一致。
- 将边界导出为 RFC 7946 WGS84 GeoJSON，每个 feature 的 `properties.code` 为六位区划代码。2014 版边界须完成核验后才可选为基准。
- 栅格需为一波段整数分类 GeoTIFF，保留真实 CRS 和 NoData。可使用全国文件或有缓冲的研究区裁剪文件。保留足够外侧数据使重投影后的区界外仍有至少一圈有效像元。
- CLCD 不透水面用于操作化度量遥感建设用地。以产品说明核对类别值，并保存重分类规则。区内缺失像元、边缘邻接无法确定和重复区界会触发校验。

## 统计面板

用 [统计数据模板](../data/socioeconomic-template.csv)，按区划代码、统计年份各填一条。人口用人，GDP 和第二产业增加值用万元。表内数值须统一单位，留空项需回查。来源列写入具体年鉴、表号或公告链接，`price_basis` 和 `boundary_basis` 记录全表统一的口径。

| 情形 | 核验与转换 |
|---|---|
| 2010 年的旧区县 | 逐年检查綦江与万盛、原大足与双桥等统计项的空间范围。仅当组分互斥且覆盖目标区时加总，保留原始表格和转换依据。 |
| 功能区跨行政区 | 查验年鉴是否已计入相关行政区，涉及拆并且无法获得可靠分项时登记缺失，暂停正式评价。 |
| 人口统计 | 使用常住人口，明确年末数或人口普查时点。 |
| 经济统计 | 优先使用同一基期的不变价序列。只能取得现价时，全表注明名义价格，并限制跨期变化解释。 |
| 历史修订 | 同一指标尽量采用同一修订口径。核查 GDP 与第二产业增加值之间的一致性。 |

原始数据目录建议为每份文件记录责任机构、标题、发布日期、有效时点、下载网址、获取日期、许可、SHA-256 和处理命令。对历史并区另存一份实际使用的旧代码到新代码映射，逐项记录合并依据。
