# 分析与验证报告

## 验证范围与证据类型

本项目将验证分为三类，避免将模拟夹具、仓库已提供的实测汇总和外部权威核验混为一谈：

1. **算法合成测试**：程序生成的几何、栅格与统计数据，用于验证算法行为、异常拦截和边界条件。
2. **仓库实测数据复核**：使用仓库内四期 CLCD 派生表、21 区归属栅格复算结果、84 条社会经济转录记录及 WebGIS 数据，检查内部一致性和跨文件关联。
3. **外部权威核验**：核对原始 CLCD 发布文件、年鉴扫描页、历史区划合并凭证和边界坐标基准。此项仍需人工归档，不能由内部自动化测试替代。

## 自动化验证

GitHub Actions 在 Python 3.12、Node.js 22 环境中执行：

- Django 配置检查、迁移、研究数据导入和模型/API 测试。
- DuckDB/Parquet 分析构建及时间留出模型计算。
- audit_study.py 数据一致性审计。
- 合成 GeoTIFF 端到端空间工作流测试。
- 熵权 TOPSIS 数值性质、常数指标、非法面板与边界条件测试。
- Web、移动端和桌面端页面/静态资源白名单测试。
- 浏览器端评价算法、转移矩阵、派生指标、Spearman 相关和权重敏感性测试。
- Docker 生产镜像构建。

CI 的 JSON/Markdown 数据审计报告与分析报告作为 GitHub Actions artifact 保存。CI 通过仅代表当前仓库固定输入和代码在该环境下通过自动化检查，不等于已在生产服务器或实体设备部署。

## 实测面板内部一致性

| 项目 | 规模 | 核验内容 |
|---|---:|---|
| 行政区目录 | 21 区 | 六位代码唯一；中心城区 9 区、主城新区 12 区 |
| 土地覆盖面板 | 84 条 | 21 区 × 4 年；九类面积之和与有效覆盖面积相符 |
| 建设用地变化 | 63 条 | 21 区 × 3 阶段；新增 − 减少 = 净增 |
| 地类转移矩阵 | 5,103 格 | 21 区 × 3 阶段 × 9 × 9 类；像元面积与前后期分类面积对账 |
| 社会经济面板 | 84 条 | 21 区 × 4 年；代码、年份、来源和质量等级齐全 |
| 主要评价样本 | 42 条 | 2020、2022 年指标均为 A 级 |
| 地图展示边界 | 21 个要素 | GeoJSON 几何有效、坐标范围符合 WGS84 |
| 评价输出 | 84 条 | TOPSIS 得分在 0—1，熵权非负且和为 1 |

执行以下命令生成带 SHA-256 输入指纹的机器可读和可读报告：

~~~bash
python audit_study.py --output outputs/data-audit
~~~

报告会明确列出已知限制：2010/2015 年 GDP 和第二产业数据含 B/C 级记录；经济序列采用当年现价；年鉴引用为转录元数据，原始扫描件与修订记录尚未完整归档；展示 GeoJSON 仅用于地图呈现，面积计算仍依赖原生等积栅格与区归属数据。

## 主要实证结果（仓库现有数据）

四期不透水面面积分别为 668.8755、976.7943、1,234.2015、1,293.8787 km²。2010—2022 年净增 625.0032 km²，增幅 93.44%。三个阶段年均净增分别为 61.5838、51.4814、29.8386 km²/年。

2020、2022 年主分析以 42 条 A 级观测重新标准化并计算熵权 TOPSIS，人口密度、单位建设用地 GDP 和单位建设用地第二产业增加值权重分别为 0.2025、0.5740、0.2235。两期排名前三均为渝中区、涪陵区和荣昌区。2020—2022 年区级扩张强度与 2022 年得分的 Spearman ρ 为 −0.378。该系数为描述性关联，不应作因果解释。
