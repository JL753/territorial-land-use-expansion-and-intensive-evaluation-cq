# 分析与验证报告

研究范围为重庆主城都市区 21 区，时点为 2010、2015、2020 和 2022 年。下列验证使用程序生成的虚构几何、土地覆盖和社会经济值。

| 研讨方案中的验证项 | 本次已验证操作 | 实测状态 |
|---|---|---|
| 多期土地覆盖和面积核算 | 四期栅格读取、等积对齐、面积与分期转移核算、建设用地重心计算。检查新增减去减少等于净扩张，邻接和非邻接新增之和等于全部新增。 | 待取得指定版本 CLCD |
| 人口和经济统计关联 | 21 个区代码×4 期准确关联，得到 84 条记录。自动测试确认缺少任一条记录即停止。 | 待获得年鉴表格并处理历史行政边界 |
| 空间数据库与页面 | PostGIS 导入 21 条区界和 84 条记录。对区界与其内部代表点执行相交查询，返回 21 条。Chromium 加载数据库版页面，验证区组筛选、区县详情和切换到基准期的空变化提示。 | 待正式区界和实测结果入库 |

## 合成结果

熵权分别约为 0.3297、0.3351、0.3352，对应人口密度、单位建设用地 GDP 和单位建设用地第二产业增加值。测试检查全部综合得分位于 0 至 1，权重和为 1。程序将区年结果、名次敏感性、阶段 Spearman 系数、分组汇总、趋势图和描述报告写入输出目录。

研讨材料提供的文献建成区面积采用原研究口径。实测后的对照应分别注明空间范围、数据产品与分类定义。合成验证结果仅用于核对计算链路。

## 实测验收条件

1. 确认四期资料的发布版本、代码、授权和覆盖范围。人工抽核边界与类别图层，并在同一边界复核各年面积。
2. 收集所有区年的常住人口、GDP 和第二产业增加值，明确单位、统计边界、时点与价格口径。保留历史并区的核算依据。
3. 生成并检查三期变化指标、四期评价排名和区组对照。对名次变化、极值、负扩张与异常重心位移回查原始数据。
4. 将正式成果导入独立 PostGIS 数据库。在网页核查典型区、四个年份和筛选结果，再用实测输出撰写论文的结果、讨论和结论。

前期云环境访问 CLCD、年鉴与行政区界数据入口均遭遇代理 403。后续附件中的裁剪数据及年鉴转录资料已用于实证复算。真实数据验证了 84 条土地覆盖匹配与 84 条社会经济关联。两个 Excel 数据页分别与对应 CSV 一致。PostGIS 导入 21 条合法 WGS84 展示几何、84 条观测，其中 42 条带暂定标识。Chromium 验证实测版的口径提示、区组筛选和详情查询。参见 [土地覆盖结果](landcover-results.md) 和 [集约利用结果](socioeconomic-results.md)。
