# 两江立体图

从研究台或桌面分析台打开「两江立体图」，也可直接访问 `/city.html`。地图由 MapLibre GL JS 5.16.0 本地资源绘制，区县趋势、用途构成由 ECharts 绘制。应用使用 WebGL。无法初始化三维视图的设备可在研究台打开二维地图。

| 工作流程 | 操作 |
|---|---|
| 区县现状 | 点击地图、区名或区县选择器，查看不透水面、阶段扩张、人口、集约得分、四期趋势和经济资料来源 |
| 土地调查 | 开关区界、水系、土地覆盖和增减变化图层。播放四期观测，或单独选择对照年份并调整透明度 |
| 立体制图 | 缩放、旋转和调节俯仰，一键切换全域和虎溪。可将区县指标按共同色阶表现为立体柱面，柱高编码专题数值 |
| 虎溪建筑 | 按名称或 OSM 对象 ID 搜索，飞到建筑或设施并点击查看细节。建筑可按用途或高度依据着色。高度显示倍率为视角参数 |
| 周边分析 | 地图选点或从弹窗选取中心，绘制范围并计算 500 米、1 公里直线半径内的设施记录和建筑代表点。可用交通、教育、医疗、生活服务、公园与运动过滤显示 |
| 建筑统计 | 用途环形图和楼层标签分布按当前半径或完整快照统计。保留源数据未记录楼层的类别 |
| 方案和成果 | 当前区县和年份可带入评价试算。保存或恢复地图视角、年份、图层和范围。可导出区县及周边 CSV、带署名地图 PNG，或打印研究简报 |

## 数据范围

- **重庆 21 区**使用项目已有区界、长江和嘉陵江以及 2010、2015、2020、2022 四期 CLCD。地类和变化图层是栅格重投影后的预览。变化色表示相邻观测期共同有效像元转入或转出不透水面。区级面积和统计始终来自完整分块核算。立体柱面仅编码选定指标，区县统计采用同一色阶。
- **重庆大学虎溪及周边**使用 2026-10-13 OpenStreetMap 快照。提取 **310 个建筑轮廓、161 条设施记录、239 条道路线**。其中 4 栋有楼层标签，在展示中每层按 3.2 米估算。306 栋使用 9 米示意拉伸。建筑拉伸倍率独立于高度标签与统计，弹窗显示依据。 [原始快照及出处](https://github.com/zhipengGui/cqu-campus-3d/blob/2cfb045b0dd7118d683eebf604c3156e61241015/data/snapshots/osm_snapshot_2026-10-13.json) · [数据来源声明](https://github.com/zhipengGui/cqu-campus-3d/blob/2cfb045b0dd7118d683eebf604c3156e61241015/data/sources.json)
- 周边统计基于球面距离，设施按 OSM 对象计数，建筑按代表点计数。快照覆盖框和越界提示用于标识可查范围。覆盖框内也可能存在未收录设施。同一设施若有多个 OSM 对象，结果按对象计数。结果用于描述样本记录，行政区人口仍采用已有区级观测。
- 地图上的建筑、设施和道路派生 GeoJSON 遵循 ODbL 1.0，保留 OpenStreetMap 署名。 [ODbL 许可](ODbL-1.0.txt) · [OpenStreetMap 数据署名](https://www.openstreetmap.org/copyright)
- 高德、百度、谷歌和 CSDN 的请求在开发环境被代理阻拦。本版采用实际可核验的公开足迹及用户提供的界面截图，页面不包含这些服务商的切片或建筑模型。

## 重建地图材料

取得固定版本的 OSM 快照，校验 SHA-256 为 `8258245aa01441cb05238189daee54cd2bb5c45824038c939d1997429198c06d`。以项目原始数据重建图层。

```bash
python tools/build_city_layers.py \
  --clcd /path/to/cq_landcover/out \
  --osm /path/to/osm_snapshot_2026-10-13.json
```

新增同口径 GeoTIFF 使用 `CQ_Metro21_LC_YYYY.tif` 文件名。重建后元数据会列出所有已生成的栅格年份。重投影采用 EPSG:3857 与最近邻重采样，研究区外和两期缺测位置透明显示。Django 通过白名单提供渲染资产。网页首次打开三维场景后缓存其资源，桌面包直接内置。地图 PNG 输出 WebGL 渲染图层及数据署名，打印简报保留所选区县指标、数据来源和已计算的周边统计。
